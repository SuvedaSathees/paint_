# Akshara Canvas Flow

MASTER PROMPT — AKSHARA PAINTS & HARDWARE

PREMIUM SCROLL-DRIVEN HERO EXPERIENCE

Build a premium, highly interactive hero section for:

BRAND:

AKSHARA PAINTS & HARDWARE

IMPORTANT:

The website reference https://buckssauce.com/ is provided ONLY as an animation and interaction reference.

Do NOT copy its branding, content, layout, illustrations, assets, or visual identity.

Take inspiration from its smooth, cinematic, scroll-driven interaction and create an ORIGINAL experience specifically for a professional paint and hardware store.

==================================================

CORE GOAL

==================================================

The hero section must create an immediate:

“WOW — WHAT A WEBSITE!”

reaction when the demo is opened.

This should NOT feel like a normal static paint-shop website.

It should feel like a premium interactive product experience where the user’s scrolling controls the story.

The hero animation must be smooth, cinematic, realistic, premium, and technically polished.

Avoid cheap-looking cartoon animations, excessive effects, random floating objects, or generic AI-generated visuals.

==================================================

COLOR & VISUAL DIRECTION

==================================================

Use a premium light theme.

Primary:

- Clean white

- Deep navy blue

- Subtle blue shades

Accent:

- Warm orange / golden-yellow used carefully

Overall feeling:

- Premium

- Professional

- Modern

- Trustworthy

- Clean

- Architectural

- High-end hardware / paint brand

Do NOT make it cyberpunk.

Do NOT use excessive neon.

Do NOT make the page black-heavy.

Use subtle gradients, soft shadows, realistic lighting, glass-like surfaces where appropriate, and excellent typography.

==================================================

HERO CONCEPT

==================================================

Create a cinematic “PAINT CAN → PAINTING TOOLS → PAINT STROKE → BRAND” story.

The hero begins with a premium realistic paint can/container positioned as the main visual focus.

The paint can should feel like a real physical product:

- realistic material

- realistic highlights

- subtle reflections

- premium studio lighting

- realistic shadows

- high-quality product-render appearance

The initial viewport should be visually minimal.

The brand name should be visible but should NOT reveal the entire story immediately.

==================================================

SCROLL-DRIVEN ANIMATION

==================================================

The animation must be controlled primarily by scroll.

Scrolling DOWN should progressively control the animation.

Do NOT make the animation simply autoplay independently of the user's scrolling.

Use scroll progress to control:

1. Camera movement

2. Paint-can rotation

3. Paint-can scale

4. Can opening

5. Tool emergence

6. Object positioning

7. Paint movement

8. Typography reveal

9. Background transitions

10. Final hero composition

The animation should feel physically connected to the user's scrolling.

Use smooth interpolation / spring-like motion so that the animation never feels abrupt.

==================================================

ANIMATION SEQUENCE

==================================================

PHASE 01 — INTRO

At the very beginning:

- Clean premium background

- Paint can centered or slightly offset

- Very subtle floating / breathing motion

- Soft studio shadow underneath

- Minimal typography

Show:

“AKSHARA”

then:

“PAINTS & HARDWARE”

Typography should feel premium and confident.

Do not overload the first screen.

--------------------------------------------------

PHASE 02 — PAINT CAN ROTATION

As the user begins scrolling:

The paint can slowly rotates.

The camera subtly moves closer.

The can should feel like a physical product being presented in a premium commercial.

Add:

- subtle reflections

- realistic lighting changes

- depth

- soft shadow movement

The rotation must be smooth and synchronized with scroll.

--------------------------------------------------

PHASE 03 — CAN OPENS

As scrolling continues:

The paint-can lid begins to open.

Make this moment visually satisfying.

The lid should rotate/open naturally.

Do NOT make it pop open suddenly.

Use easing and realistic movement.

The camera should slightly zoom toward the opening.

--------------------------------------------------

PHASE 04 — PAINTING TOOLS EMERGE

After the can opens, painting tools begin emerging from the can.

Reveal them sequentially rather than all at once.

Possible tools:

- Paint brush

- Paint roller

- Putty knife / scraper

- Measuring tape

- Sandpaper

- Masking tape

- Other relevant professional painting / hardware tools

Each tool should have:

- individual motion

- slight rotation

- depth

- realistic shadow

- natural emergence from the container

The tools should appear to be physically coming out of the paint can.

Avoid random floating.

The animation should feel choreographed.

--------------------------------------------------

PHASE 05 — PAINT STROKE

As the scroll continues:

A beautiful realistic paint stroke begins appearing across the scene.

The stroke should feel like actual wet paint being applied.

The stroke can act as a transition element.

It should gradually expand/reveal content.

Use the paint stroke to transition from the product-focused scene into the main brand message.

The paint should have:

- realistic thickness

- subtle shine

- natural edges

- smooth movement

Avoid a flat SVG-looking stripe.

--------------------------------------------------

PHASE 06 — TOOL MOVEMENT

Create a moment where the brush / roller moves naturally across the screen.

The movement should visually connect with the paint stroke.

For example:

Brush/roller moves →

Paint appears →

Paint stroke expands →

Next section is revealed.

This should feel like one continuous physical action.

--------------------------------------------------

PHASE 07 — BRAND REVEAL

Once the paint stroke completes:

Reveal the main hero message.

Example:

AKSHARA

PAINTS & HARDWARE

Supporting line:

“Colors that transform spaces.”

Use elegant typography.

Add a premium CTA:

EXPLORE OUR PRODUCTS →

Secondary CTA:

VISIT OUR STORE

Keep the typography clean and powerful.

==================================================

CAMERA EXPERIENCE

==================================================

The camera should behave like a premium commercial product shoot.

Use:

- slow push-ins

- subtle pull-backs

- controlled rotations

- depth transitions

- smooth perspective changes

Do NOT constantly shake or rotate the camera.

Every camera movement must have a purpose.

The user should feel as though they are moving through a small cinematic story.

==================================================

SCROLL FEEL

==================================================

Scrolling should feel extremely smooth.

Use:

- scroll-linked animation

- interpolation

- easing

- momentum

- pinned hero section

- controlled animation timeline

The hero can remain pinned while the animation progresses.

Example progression:

0% — Paint can introduction

15% — Can rotation

30% — Lid opens

45% — First tools emerge

60% — More tools emerge

70% — Paint stroke begins

85% — Brush/roller action

100% — Final AKSHARA PAINTS & HARDWARE reveal

Do not make these percentages rigid if another timing produces a better visual result.

==================================================

FINAL HERO STATE

==================================================

At the end of the hero animation:

Create a premium composition.

Paint can:

- positioned elegantly

Painting tools:

- arranged naturally around it

Paint stroke:

- integrated into composition

Brand:

AKSHARA PAINTS & HARDWARE

Main message:

“Bring Your Space to Life.”

CTA buttons visible.

The final state must look like a premium real company website, not a demo animation.

==================================================

MICRO INTERACTIONS

==================================================

Add subtle premium interactions:

- CTA hover animations

- button magnetic / slight movement effect

- text reveal

- subtle cursor interaction

- tool hover movement if appropriate

- gentle parallax

- smooth navigation transition

Keep these subtle.

Do NOT make everything move.

==================================================

TECHNICAL REQUIREMENTS

==================================================

Use modern frontend architecture.

Preferred:

React / Next.js

GSAP

ScrollTrigger

Three.js where genuinely useful

CSS / Tailwind

Use GSAP ScrollTrigger for the main scroll-driven timeline.

If 3D assets are unavailable, create the closest premium experience possible using optimized layered assets / CSS / SVG / canvas rather than producing a broken or unrealistic 3D scene.

Prioritize:

60 FPS smoothness

Fast loading

Responsive behavior

Clean component architecture

Reusable animation components

Lazy-load heavy assets.

Do not allow the animation to block the initial page render.

Tool emergence

Paint stroke

Brand reveal

Touch scrolling must control the animation naturally.
